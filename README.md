# Kotlin File Scanner

أداة سطر أوامر بلغة Kotlin تفحص الملفات أمنياً (فحص ساكن، لا تنفّذ أي ملف).

## ماذا تكشف؟

| الفحص | الأمثلة | الخطورة |
|---|---|---|
| أسرار مسرّبة | مفاتيح AWS/Google، توكنات GitHub/Slack، المفاتيح الخاصة، كلمات مرور مكتوبة في الكود | MEDIUM – CRITICAL |
| بصمات خبيثة معروفة | تطابق SHA-256 مع قائمة تقدّمها أنت | CRITICAL |
| امتدادات مخادعة | `invoice.pdf.exe` | HIGH |
| تنفيذيات متنكّرة | ملف بترويسة EXE/ELF لكن امتداده `.txt` مثلاً | MEDIUM |
| أنماط مشبوهة | تنزيل ثم تنفيذ مباشر (curl إلى sh)، PowerShell مشفّر، reverse shell | LOW – HIGH |
| صلاحيات | ملف قابل للكتابة من الجميع (Linux/macOS) | MEDIUM |

القيم السرّية تُعرض مقنّعة (أول 4 أحرف فقط) حتى لا يتسرّب السر في التقرير نفسه.

## التشغيل

```bash
# أول مرة فقط: إنشاء Gradle wrapper
gradle wrapper

# فحص مجلد
./gradlew run --args="/path/to/folder"

# مع قائمة بصمات خبيثة + تقرير JSON
./gradlew run --args="/path/to/folder --hashes bad-hashes.txt --json"

# تشغيل الاختبارات
./gradlew test
```

خيارات:

- `--hashes <file>` ملف نصي فيه بصمة SHA-256 في كل سطر (الأسطر التي تبدأ بـ `#` تُتجاهل)
- `--json` تقرير JSON
- `--fail-on <LEVEL>` يرجع كود خروج 1 إذا وُجدت نتيجة بهذه الخطورة أو أعلى (الافتراضي HIGH)

## التكامل مع GitHub Actions

الملف `.github/workflows/build.yml` يبني المشروع ويشغّل الاختبارات ثم يفحص المستودع نفسه عند كل push وpull request.
